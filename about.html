About Me

A journey of growth, learning, and self-discovery

Bio

I'm a passionate learner currently enrolled in a comprehensive web development program. With a background in design thinking and creative problem-solving, I'm transitioning into the world of code to build meaningful digital experiences. My journey began with a curiosity about how websites work behind the scenes, and now I'm dedicated to mastering the craft of creating intuitive, accessible, and beautiful web applications.

When I'm not coding, you can find me exploring new hiking trails, reading science fiction novels, or experimenting with digital art. I believe that the best solutions come from combining creativity with technical precision, and I'm excited to bring that philosophy to every project I undertake.

Goals in This Program

Short-term (Next 3 Months)

  • Master HTML, CSS, and JavaScript fundamentals
  • Build 5 complete responsive websites
  • Understand accessibility best practices
  • Learn Git and version control workflows

Long-term (Program Completion)

  • Develop a professional portfolio showcasing diverse projects
  • Collaborate on team-based development projects
  • Gain confidence in debugging and problem-solving
  • Prepare for entry-level frontend development roles

Areas of Low Confidence

JavaScript Algorithms

I'm still working on understanding complex data structures and algorithmic thinking. While I can build functional interfaces, I want to deepen my knowledge of efficient problem-solving patterns.

CSS Grid & Flexbox

Basic layouts are becoming comfortable, but I struggle with more advanced grid patterns and responsive breakpoints. I need more practice with real-world layout challenges.

Debugging Complex Issues

Finding and fixing bugs in larger codebases feels overwhelming. I want to develop systematic debugging approaches and become more comfortable reading error messages.

Extra Thoughts

The Power of Patience

I've learned that coding is as much about patience as it is about logic. Sometimes the solution isn't about working harder, but about stepping back and seeing the problem from a different angle.

Community Matters

One of the biggest surprises has been how supportive the developer community is. Stack Overflow, GitHub, and online forums have shown me that no one succeeds alone—we all stand on the shoulders of those who came before us.

Design Meets Code

There's a beautiful intersection between design and development that I'm just beginning to explore. Clean code isn't just functional—it's elegant, readable, and maintains the same care as great design.
